This repository exists as a living history of the changes for the constitution of Alpha Sigma Phi Beta Psi. 
It was created on 1/15/2026 as a result of years of confusion over a lack of recordkeeping for constitutional changes, as well as a desperate need for constitutional restructuring.
The idea was put forth by Nate Diller (Roster Number 664), worked on primarily by Zachary Polo (Roster Number 833), and inspired by Eric Hammel (Roster Number ???).
